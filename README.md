# Amdox Internship Projects

A collection of projects developed during my internship at Amdox Technologies, covering data analytics and application development.

## Projects

### 1. Cryptocurrency Analytics

A Python-based data analytics project focused on cleaning, processing, and analyzing cryptocurrency market data.

The project explores cryptocurrency trends, price movements, trading volume, and volatility across different coin pairs and date ranges.

#### Key Areas

- Cryptocurrency data cleaning and preprocessing
- Exploratory data analysis
- Price and volume analysis
- Trend analysis
- Volatility analysis
- Data visualization
- Analysis across different coin pairs and date ranges

#### Technologies

- Python
- Pandas
- NumPy
- Matplotlib

---

### 2. AI Task Optimizer

A task-management project developed during the internship that explores AI-based approaches for organizing and optimizing tasks.

The project focuses on helping users manage tasks and improve task organization through an application-based approach.
